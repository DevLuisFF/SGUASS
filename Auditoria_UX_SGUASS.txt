1. RESUMEN EJECUTIVO
================================================================================

1.1 VEREDICTO
--------------------------------------------------------------------------------

SGUASS tiene una base funcional y una intención de producto clara: dashboard por
roles, KPIs, gráficos, cálculos automáticos y acciones rápidas. Sin embargo, la
experiencia actual está por debajo de un estándar profesional.

El problema más grave no es estético: varias acciones principales del dashboard
llevan a páginas que no existen. Eso rompe la confianza y bloquea tareas
completas de administración, secretaria, docencia y estudiantes.

Un usuario experimentado puede operar el sistema si ya conoce los módulos. Un
usuario nuevo, un usuario móvil o una persona con baja visión encuentra barreras
severas: enlaces muertos, contraste insuficiente, controles de 14 px, formularios
sin guía, mensajes con alert() nativo y un modal de calificaciones que no se
adapta a pantallas pequeñas.

La buena noticia es que la mayoría de los problemas se corrige con cambios
acotados y nativos de PHPRunner: enlaces correctos, CSS global, un JavaScript de
endurecimiento, propiedades de campo y unos pocos snippets.

1.2 PUNTUACIÓN POR DIMENSIÓN
--------------------------------------------------------------------------------

  Navegación y arquitectura de información      40/100    Enlaces muertos

1.3 LO QUE FUNCIONA
--------------------------------------------------------------------------------

  - La estructura List -> Add -> Edit -> View -> Search es reconocible y
    consistente con PHPRunner.

  - El dashboard tiene una intención correcta: segmentar por rol, mostrar KPIs
    y ofrecer accesos directos.

  - Los listados incluyen títulos en los iconos (title="Editar", title="Ver"),
    lo que ya es un punto de partida de accesibilidad.

  - El login tiene un bloque de mensaje con role="alert", útil para errores de
    autenticación.

  - Los cálculos automáticos de mora, promedio y condición son valiosos si se
    les agrega transparencia y control.

1.4 TOP 5 RIESGOS
--------------------------------------------------------------------------------

  1. Enlaces muertos en el dashboard (CRÍTICA).
     404 en acciones de administración, secretaria, docencia y estudiantes.

  2. Contraste insuficiente del tema Flatly (ALTA).
     Enlaces, badges y textos muted por debajo de WCAG AA.

  3. Objetivos tactiles de 14 px y busqueda sin nombre accesible (ALTA).
     Errores de toque y barreras para lectores de pantalla.

  4. Formularios sin obligatorios, ayuda ni mascara de cédula (ALTA).
     Datos inválidos, duplicados y retrabajo.

  5. alert() nativo, loading falso y gráficos dependientes de CDN (ALTA).
     Interrupciones, falsa sensación de carga y dashboard vacío si falla la red.

1.5 ÉTICA Y DARK PATTERNS
--------------------------------------------------------------------------------

No se encontraron patrones oscuros deliberados como urgencia falsa, culpa,
suscripciones ocultas o confirmaciones enganosas. El riesgo etico está en dos
puntos:

  - Mora automatica silenciosa: el sistema modifica el monto y el estado sin
    explicar por que (pageevents_pagos.js). Aunque sea correcto, debe ser
    transparente y editable.

  - Accion destructiva poco senalizada: "Borrar articulos seleccionados" usa
    estilo neutro (btn-default) y una terminología equivocada, lo que reduce la
    percepcion de riesgo.

Recomendación etica: toda automatizacion que cambie dinero o estado academico
debe mostrar que hizo, por que lo hizo y como revertirlo.

2. ALCANCE Y MÉTODO

2.1 ALCANCE
--------------------------------------------------------------------------------

Se auditaron estas pantallas y flujos:

  - Listados: estudiantes_list, pagos_list, notas_list, carreras_list,
    matriculas_semestre_list, asistencias_list.
  - Alta: estudiantes_add y formularios equivalentes.

  - Vista: estudiantes_view y vistas equivalentes.
  - Busqueda simple y busqueda avanzada.
  - Login global.
  - Menu superior y dashboard por roles.
  - Master-Details: carreras_masterlist y equivalentes.
  - Elementos globales: loading, modales, notificaciones, tablas.

2.2 FUENTES REVISADAS
--------------------------------------------------------------------------------

  - SGUASS.phpr (XML del proyecto, 2.1 MB, PHPRunner 10.0 build 32290).
  - output/templates/*.htm.
  - output/include/pages/*.php.
  - output/include/runnerJS/events/*.js.
  - output/styles/pages/*.css.
  - output/styles/bootstrap/flatly/css/bootstrap-theme.min.css.
  - output/classes/layout.php y output/classes/pdlayout.php.

2.3 LIMITACIONES
--------------------------------------------------------------------------------

  - La auditoría es estática: no se ejecuto la aplicacion en un navegador real.
  - Los ratios de contraste se calcularon con la formula WCAG 2.1.
  - No se hicieron pruebas con lector de pantalla ni con dispositivos fisicos.
  - No se imputan problemás de styles/general.css porque ese archivo no se carga
    en el layout Bootstrap de las páginas auditadas.
  - Las rutas y lineas corresponden al estado del proyecto en la fecha indicada.

2.4 CONVENCIONES DE SEVERIDAD
--------------------------------------------------------------------------------

  CRÍTICA  Bloquea una tarea principal o produce un fallo de confianza grave.
  ALTA     Impide o dificulta seriamente una tarea; viola WCAG AA.
  MEDIA    Genera friccion, inconsistencia o riesgo de error, pero hay workaround.
  BAJA     Mejora deseable; no incluida en esta matriz.

  Severidad       : ALTA

  Ubicacion       : templates/estudiantes_add.htm:67-73
  Estado actual   : Aparecen antes de guardar el registro.

  Severidad       : MEDIA

  Ubicacion       : templates/estudiantes_add.htm:248-265

6.5.4 Formato monetario en carreras

Donde:
  include/runnerJS/events/pageevents_carreras.js, eventos de Alta y Edicion.

Problema:
  Formatea en input/keyup con ctrl.setValue(), lo que mueve el cursor.

Solucion:
  Formatear en blur y limpiar antes de guardar.

    function bindMoney(pageObj, pageid) {
      var moneyFields = [
        'costo_matricula',
        'costo_semestre',
        'costo_derecho_examen'
      ];

      function onlyDigits(v) {
        return String(v == null ? '' : v).replace(/\D/g, '');
      }

      function formatMiles(v) {
        var n = onlyDigits(v).replace(/^0+(?!$)/, '');
        return n ? n.replace(/\B(?=(\d{3})+(?!\d))/g, '.') : '';
      }

      moneyFields.forEach(function (name) {
        var ctrl = Runner.getControl(pageid, name);
        if (!ctrl) return;

        ctrl.on('focus', function () {
          ctrl.setValue(onlyDigits(ctrl.getValue()));
        });

        ctrl.on('blur', function () {
          ctrl.setValue(formatMiles(ctrl.getValue()));
        });
      });

      pageObj.on('beforeSave', function () {
        moneyFields.forEach(function (name) {
          var ctrl = Runner.getControl(pageid, name);
          if (ctrl) ctrl.setValue(onlyDigits(ctrl.getValue()));
        });
        return true;
      });
    }

    Runner.pages.PageSettings.addPageEvent(
      'carreras', Runner.pages.constants.PAGE_ADD, 'afterPageReady',
      function (pageObj, proxy, pageid) {
        bindMoney(pageObj, pageid);
      });

    Runner.pages.PageSettings.addPageEvent(
      'carreras', Runner.pages.constants.PAGE_EDIT, 'afterPageReady',
      function (pageObj, proxy, pageid) {
        bindMoney(pageObj, pageid);
      });

      var monto = Runner.getControl(pageid, 'monto');
      var mora = Runner.getControl(pageid, 'multa_mora');
      var moraAuto = false;

      function hoyISO() {
        var d = new Date();
        var m = d.getMonth() + 1;
        var dia = d.getDate();
        return d.getFullYear() + '-' +
          (m < 10 ? '0' + m : m) + '-' +
          (dia < 10 ? '0' + dia : dia);
      }

      function calcularMora() {
        var fv = fechaVenc.getValue();
        var m = parseInt(String(monto.getValue()).replace(/\D/g, ''), 10) || 0;
        if (!fv || m <= 0) return;

        var p = fv.split('-');
        var venc = new Date(+p[0], +p[1] - 1, +p[2]);
        var hoy = new Date();
        hoy.setHours(0, 0, 0, 0);

        if (venc < hoy) {
          var dias = Math.floor((hoy - venc) / 86400000);
          var periodos = Math.max(1, Math.ceil(dias / 30));
          var valor = Math.round(m * 0.02 * periodos);
          mora.setValue(valor);
          moraAuto = true;

          if (window.SGUASS && SGUASS.notify) {
            SGUASS.notify(
              'Mora calculada: ' + periodos +
              ' periodo(s) de 30 dias al 2%. Puedes editarla.',
              'info', 7000
            );
          }

          if (estado.getValue() === 'Pendiente') {
            estado.setValue('Vencido');
          }
        } else {
          mora.setValue(0);
          moraAuto = false;
          if (estado.getValue() === 'Vencido') {
            estado.setValue('Pendiente');
          }
        }
      }

      mora.on('change', function () { moraAuto = false; });
      fechaVenc.on('change', calcularMora);
      monto.on('change', function () { if (!moraAuto) calcularMora(); });

      estado.on('change', function () {
        if (estado.getValue() === 'Pagado' && !fechaPago.getValue()) {
          fechaPago.setValue(hoyISO());
        }
        if (estado.getValue() !== 'Pagado') {
          fechaPago.setValue('');
        }
      });
    }

    Runner.pages.PageSettings.addPageEvent(
      'pagos', Runner.pages.constants.PAGE_ADD, 'afterPageReady',
      function (pageObj, proxy, pageid) {
        bindMora(pageObj, pageid);
      });

    Runner.pages.PageSettings.addPageEvent(
      'pagos', Runner.pages.constants.PAGE_EDIT, 'afterPageReady',
      function (pageObj, proxy, pageid) {
        bindMora(pageObj, pageid);
      });

6.5.6 Condición de notas

Donde:
  include/runnerJS/events/pageevents_notas.js, eventos de Alta y Edicion.

Problema:
  Usa >=60 -> Aprobado; si no -> Reprobado, y no coincide con el dashboard.

Solucion:
  Una sola funcion de condición.

    function condicion(prom) {
      if (prom < 30) return 'Inhabilitado por Proceso';
      if (prom < 60) return 'A Examen Extraordinario';
      return 'Aprobado';
    }

    function bindNotas(pageObj, pageid) {
      var p1 = Runner.getControl(pageid, 'parcial1');
      var p2 = Runner.getControl(pageid, 'parcial2');
      var promedio = Runner.getControl(pageid, 'promedio');
      var cond = Runner.getControl(pageid, 'condicion');
      var condManual = false;

      function recalcular() {
        var a = parseFloat(p1.getValue()) || 0;
        var b = parseFloat(p2.getValue()) || 0;
        if (a <= 0 && b <= 0) return;

        var prom = Math.round(((a + b) / 2) * 10) / 10;
        if (promedio) promedio.setValue(prom);
        if (cond && !condManual) cond.setValue(condicion(prom));
      }

      if (cond) {
        cond.on('change', function () { condManual = true; });
      }
      if (p1) p1.on('keyup change', recalcular);
      if (p2) p2.on('keyup change', recalcular);
    }

    Runner.pages.PageSettings.addPageEvent(
      'notas', Runner.pages.constants.PAGE_ADD, 'afterPageReady',
      function (pageObj, proxy, pageid) {
        bindNotas(pageObj, pageid);
      });

    Runner.pages.PageSettings.addPageEvent(
      'notas', Runner.pages.constants.PAGE_EDIT, 'afterPageReady',
      function (pageObj, proxy, pageid) {
        bindNotas(pageObj, pageid);
      });
